# the-8-am-zoomies

## 基础玩法说明

Z键跳跃，C键+方向键（比如↑+→就是向右上冲刺）可以进行八向冲刺，冲刺紧接跳跃会跳得更高。

场景中会有各类道具和大量隐藏路径，玩家的目标是探索地图，解锁新的道具（主要为各类共享单车，例如最基础款的单车可以加速，且单车遇到尖刺会发生爆胎，给小猫提供一个推进力），寻找前往终点的最优路径。

在游戏的过程中，玩家会不断发现新的移动方式，也会逐渐解锁新的剧情，慢慢了解游戏的真相。

## 游戏设定

将平台跳跃与限时速通结合。

游戏的主要设定分表里两层，表面上看是一只猫需要借助校园里的共享单车赶早八，实际上是作为一名大学生探索和重拾自我的旅途。

游戏有一个真结局和一个假结局，假结局就是小猫按时赶到了教室，而真结局是小猫到达了未名湖。通关一次假结局才能获取达成真结局必要的前置道具。
